# data/ 数据目录

| 子目录 | 用途 | 提交策略 |
|---|---|---|
| `templates/` | 文化资料录入模板（YAML） | 提交 |
| `demo/` | 演示用小型数据（明确标注为演示数据） | 提交 |
| `raw/` | 原始文化资料（需确认来源与授权后放入） | 提交说明，大文件走网盘 |
| `processed/` | 清洗切分后的中间产物、本地向量索引 | 不提交（.gitignore） |
| `testsets/` | AI 黄金测试集（RAG / 角色 / 越级 / 安全） | 提交 |

## 红线

1. 任何进入 `processed/` 并参与检索的内容必须已通过人工审核（`review_status=reviewed`）。
2. 文化内容必须按四级标注：`fact`（可靠史实）/ `disputed`（争议观点）/ `legend`（民间传说）/ `fiction`（艺术化虚构）。
3. 无真实来源的数据统一标注【待补充】，不得伪造。
