# 2026-10-17 后续问题修复记录

按审查编号逐项验证、单独提交；问题 4 已在 eeeecec 完成。以下验证不包含真实付费模型调用，也不修改既有业务数据库。

## 问题 1：默认 CI 与真实 AI 验收隔离

默认 Playwright 排除真实 AI 用例；新增独立配置和脚本，要求显式费用开关及验收栈 URL，且不启动本地服务。真实 AI 用例另有防误运行检查，并拒绝把 Mock 当作真实模型。CI 固定使用 Mock/无 Embedding。

验证：默认收集 10 项；未授权真实 AI 配置退出；显式开关下仅列出桌面/移动 2 项真实 AI 用例（仅列表，不执行）。前端 lint 通过。

## 问题 2：模型等待期间不占数据库写事务

聊天先只读预检版本/幂等回执，复制检索输入后结束读取事务，再调用 Embedding/模型；生成完毕后才用短事务 CAS 提交奖励、日志和回执。提交前重新检查 NPC 访问与资料内容/审核版本，等待期间同一旅程变化或证据撤销时返回 409，不保存过期回复。重放和过期版本在模型调用前处理。

验证：4 项新增回归（含参数化）：模拟模型等待时，另一用户创建旅程不阻塞；同一旅程并发修改及撤审均拒绝旧回复且无对话残留；幂等重放/过期版本不重复生成。均使用本地事件同步和临时 SQLite，无真实模型。相关 61 项测试通过。

## 问题 3：正确引用 ID 不能替模型事实背书

采用可核验片段展示：模型选择完整原文句子，逐段检查来源 ID 与原文包含关系、句子边界，拒绝伪造或删去限定/否定的半句；模型自由改写正文不直接展示。旧格式回复回退展示所引原文，响应记录 grounding_mode。相比任意改写更保守，但避免将新增年份、收藏地等事实挂到正确引用上。未额外调用模型做“自我评分”；原始语料真实性仍须人工审核。

验证：6 项新增回归覆盖正确 ID 搭配错误年份/馆名、正确完整片段、伪造片段、半句、越引用和删除否定；事实正文不含模拟模型捏造的 1888 年/大英博物馆。无真实模型调用。

## 问题 5：正式检索与评测统一 Top-K

抽取共享 retrieve_knowledge：按原有块分数稳定排序后取 K 个独立 knowledge_id，每篇保留最优块。正式聊天、后台检索与三臂/生成评测共用此入口；配置明确 top_k_unit=knowledge，原始块排序函数保留供底层机制测试使用。历史评测文件不覆盖，不冒充新实验。

验证：4 项新增回归，覆盖关键词、向量、混合三种模式及真实聊天路由。构造 A 的六块先于 B 排名的长资料，正式聊天和评测均取得 A、B，并排除未来章节。

## 问题 6：排序答错后的反馈与排列保留

初始化依赖改为题目 ID 与选项内容签名，不再依赖每次 API 刷新都会变化的数组引用。相同内容刷新保留用户排列和反馈；切题或选项实际变化仍重置。

验证：3 项真实组件回归，覆盖答错后刷新、切题、同题选项变更。原 9 项加新增 3 项单测均通过，lint、类型检查与生产构建通过；使用前轮已记录的 /tmp Linux 原生依赖进行验证，未改锁文件。

## 问题 7：回执不再重复保存全量快照

新回执只存动作业务结果，重放时读取最新权威快照，保持幂等语义并兼容旧格式。新增历史压缩工具，默认仅输出计划，显式 --apply 才删除旧回执中的快照副本；不会删除旅程历史或幂等结果。本轮未操作既有业务数据库。

验证：80 次追加事件后，前后各 40 条回执 JSON 总量持平；旧格式重放仍返回最新快照；压缩默认不写、显式压缩减少字节且重放不变，再次执行无候选。

## 问题 8：实验改为配置对照，撤回单守卫因果结论

脚本和预检计划明确记录：四组共享输入过滤，多项配置同时变化，full_pipeline 是仅调用 NPC respond() 的历史组名；未执行运行时动作守卫、旅程变更或 SafetyLog 写入。guard_accepted 仅为生成诊断，answered 也包含诊断未通过的原回答。报告撤回“动作守卫不可替代”“仅完整管线零调用”“校验已拦截输出”等无对应证据的表述。

历史 v2 的 records、summaries、usage、模型版本和运行时间保持不变，仅修正解释元数据，并保存测量部分的 SHA-256 供核对。新运行输出 generation-comparison-v2，默认另存 generation-comparison-results.json，避免覆盖历史；仍需显式授权才调用提供方。本轮未进行付费实验，历史成绩不代表当前 v5。

验证：四组注入都在调用提供方前短路；真实 NPC 回答函数返回动作提议时仅记录提议、不会测试运行时接受；引用诊断失败仍保留原回答；默认/--list 均只输出计划与实验边界；未授权程序调用被拒绝。预检的 Embedding 上限按三组独立检索累计。历史测量部分哈希一致。后端完整回归 162 项通过、1 项跳过，Ruff 通过。

## 后续配置：知识自动发布

根据当前部署要求，seed 不再等待人工审核：故事下所有知识统一为 `reviewed`、`is_demo=false`，以 `auto_published` 标识发布来源，并在缺失或过期时重建切片。这样新环境执行迁移和 seed 后即可供关键词/混合检索使用；该状态不等同于事实核验或授权证明。
