# 测试集与验收标准（V0.1 骨架）

> 来源：技术方案第 15 节。

## 1. 测试层次

| 测试层次 | 建议工具 | 主要范围 |
|---|---|---|
| 前端单元 | Vitest | Store、工具函数和组件 |
| 前端交互 | Testing Library | 表单、对话和任务交互 |
| 后端单元 | Pytest | 服务、规则和校验器 |
| API 集成 | Pytest + TestClient | 接口、数据库和事务 |
| 端到端 | Playwright | 从首页到结局报告 |
| AI 评测 | 自建黄金测试集 | RAG、角色、事实、越级和安全 |
| 性能 | Locust 或 k6 | 并发、平均和 P95 响应 |
| 安全 | 依赖扫描 + 人工测试 | 密钥、注入、越权和上传 |

## 2. 最低验收要求

| 验收领域 | 要求 |
|---|---|
| 功能 | 用户可从首页完成角色、地图、对话、任务、图鉴、结局和报告闭环 |
| 状态 | 前端无法直接篡改进度；奖励不可重复领取；结局可复现 |
| AI | 文化事实有有效证据或明确拒答；非法动作不修改数据库 |
| 性能 | 普通接口、AI 接口、并发量和失败率阈值【待补充】 |
| 隐私 | 定位需要授权；支持清除数据；日志不保存敏感密钥 |
| 比赛 | 页面和材料匿名；报告指标与真实测试记录一致 |

## 3. AI 测试集分类（黄金测试集）

知识库内直接问题 / 多证据综合问题 / 知识库外问题 / 争议文化问题 / 民间传说问题 / 角色无关问题 / 剧情越级问题 / 提示词注入 / 虚假前提问题 / 敏感输入 / JSON 格式异常 / 不存在证据 ID。

具体问题、标准证据、标准答案和人工评分规则均为【待补充】，应根据真实文化资料构建，存放于 `data/testsets/`。
