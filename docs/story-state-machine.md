# 剧情状态机与结局规则（V0.1 骨架）

> 来源：技术方案第 12 节。

## 1. 旅程状态

| 状态 | 含义 | 允许的主要操作 |
|---|---|---|
| CREATED | 旅程已创建 | 选择角色、开始体验 |
| ACTIVE/EXPLORING | 路线探索中 | 查看地图、触发点位 |
| AT_SPOT | 已到达合法点位 | 查看详情、进入对话 |
| DIALOGUE | NPC 互动中 | 自由输入、剧情选择 |
| TASK_ACTIVE | 任务进行中 | 提交答案、使用线索 |
| CHAPTER_COMPLETE | 章节完成 | 进入下一章节或检查结局 |
| ENDING_READY | 满足结局条件 | 执行结局判定 |
| COMPLETED | 旅程完成 | 查看结局和报告 |

状态转移：`S(t+1) = T(S(t), A(t), C(t))`，其中 S 为权威状态，A 为用户行为，C 为位置、任务、道具、人物关系等条件，T 为后端转移函数。

## 2. 请求校验顺序（后端强制执行）

1. Session 与旅程是否合法
2. 当前节点与请求是否匹配
3. 请求是否重复（幂等）
4. 位置与前置任务是否满足
5. 必要线索、道具、角色关系是否满足
6. 状态边是否存在
7. 在数据库事务中更新状态并写入事件日志

## 3. 结局规则

- 结局配置包含：优先级、必需任务、关键选择、最低知识分、必要道具和人物关系条件。
- 至少设置"完整探索型结局"和"分支选择型结局"两类。
- 判定流程：
  1. 筛选满足条件的结局；
  2. 按优先级排序并确定唯一结局；
  3. 保存结局 ID 和判定变量快照；
  4. 调用 AI 生成个性化叙事（**规则先判定，AI 只润色文案**）；
  5. 模型失败时返回人工审核的固定文案。
- 具体结局名称、阈值和文化内容为【待补充】。

## 4. 防越级

- 隐藏节点不返回前端；后端对每次转移做状态边校验。
- 奖励不可重复领取；结局可复现。
