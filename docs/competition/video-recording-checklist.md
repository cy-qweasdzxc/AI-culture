# 演示视频手动录制步骤与检查清单

当前交付为4分钟[分镜源稿](video-storyboard.md)与本操作单，尚无完成的MP4。视频为官方可选材料：若提交，格式MP4，时长3-5分钟，文件不超过300MB。没有录制设备/软件或实际录制条件时，本项保持待办，不能把自动化截图当作已完成的视频。

## 录制前

- [ ] 按代码包README配置隔离演示数据库并迁移、初始化；使用可清除的匿名旅程。
- [ ] 启动后端与前端，核实模式为后端API；记录版本与运行日期。
- [ ] 文化seed仍是14条pending且未索引。录制必须显示证据不足拒答与Mock标识，不伪装真实文化RAG或真实模型。
- [ ] 使用干净浏览器配置，关闭书签栏、个人头像、通知、其他标签与开发者工具；不拍桌面账号、文件系统路径或终端环境。
- [ ] 管理账号只在录制者本地配置，密码/签名密钥不放分镜、不录输入过程；录制前登录，再检查没有显示个人资料。
- [ ] 准备1920×1080或1280×720画面，页面缩放固定；先试录10秒确认中文、音量、鼠标与文件输出。
- [ ] 参赛团队编号待补时保留审阅稿标签；作品中不出现团队学校名称、LOGO与指导教师身份。

## 录制、导出与复核

1. 采用录屏工具的单窗口/指定区域录制；使用已授权的音乐与图像，或者仅录应用与本人旁白。设备或软件不可用时保持未录制状态。
2. 根据分镜录制，并观看原始成片；出现密钥、个人信息或团队身份泄露时重新录制相应片段，不依靠播放器裁剪隐藏。
3. 导出MP4（建议H.264视频与AAC音频）；检查画面清晰、语音可懂、字幕准确，时长在180-300秒且文件小于300MB。
4. 打开导出文件从头到尾播放，核对全部事实、状态、提供方标识、免责声明与字幕；保存实际时长、字节数、SHA256和审核记录。
5. 人工填写最终团队编号后按官方格式命名：`团队编号-智能文化-城迹入戏-演示视频.mp4`。由参赛团队上传并验证可播放；本次未上传。
