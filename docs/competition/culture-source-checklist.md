## 审核完成后的操作

以下仅描述未来流程，本次未调用任何更新／审核／发布接口。首先确认 `is_demo` 的变更依据和全部许可，不直接导入候选 JSON。原清单生成脚本现在默认拒绝覆盖已有文件；本轮实际验证退出码2、文件SHA不变且零DB调用。若人工明确选择覆盖，仍应先合并本文件的来源核对记录，不能用空表代替审核。

1. 在管理端用 `PUT /api/admin/knowledge/{id}` 更新 `source`、`source_url`、`license` 等字段（`version` 必须匹配，修改会自动撤销既有审核与索引）。
2. 用 `POST /api/admin/knowledge/{id}/review`，带 `version`、`status=reviewed`、`reviewer`、`confirm_sources=true`。
3. 用 `POST /api/admin/knowledge/{id}/publish` 建立索引；配置了 Embedding 时会同时生成向量。
4. 仅在人工批准资料进入正式索引后，才可用正式证据集运行检索对照评测。当前合成 Mock 评测及历史日志不能替代真实文化回答质量或来源审核。

## 核对方法与限制

本次实际访问 20 个公开机构来源候选（含两个 UNESCO 官方 ICOMOS 评估 PDF），按原 14 条逐项记录支持范围，并检查对应图鉴和任务是否把设计理念或轶闻写成史实。网页正文仅用于核对与简短释义，没有抓取整页或图片入正式知识库。未访问成功或只见搜索摘要的页面不列为正文证据；未取得争议双方原始研究时明确写待核。

网页显示的发布日期与 URL 路径年月可能不同，使用实际显示日期；未显示则保留空值。苏博页面的工具 `find` 曾漏检关键词，已用分段 `open` 实际读到坡顶与山水章节。ICOMOS PDF 文本有 OCR 字误，名单与名录页、园林局页交叉核对；古籍转录未与原刻校勘。古籍原作、馆藏图像、网页释文和摄影的权利不能合并判断；Met 的 Public Domain 图像标签及 UNESCO 部分简介的许可均不构成本项目整体授权。
