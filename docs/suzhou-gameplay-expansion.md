# 苏州路线提问与支线挑战扩展

接手运行、数据升级与复现测试见 [苏州扩充交接文档](suzhou-expansion-handoff.md)。

## 设计方向

- 为平江路、耦园、狮子林、拙政园、苏州博物馆分别提供 13 条推荐问题，五站合计 65 条；其中保留五道原有主线入口问题。
- 推荐问题按街巷生活、园林营造、历史人物、古今建筑、史实辨析、线索推理六类筛选。问题仅用现有演示种子和知识条目中的信息；资料没有定论时，问题应询问现有资料能确认什么，并由服务端 RAG 决定如何回答。
- 推荐仅作提问入口，不改变服务端 RAG 的资料、证据等级、拒答策略或剧情状态。明确区分已确认信息、争议说法和剧情创作，例如《雨巷》与丁香巷的关系、乾隆题“真趣”轶闻和“守园灯”。
- 推荐问题按当前点位和角色范围过滤。阿蘅覆盖耦园、狮子林、拙政园；不可把她的默认点位套用到其他园林。保留自由提问、按主题切换、换一批和已问过滤。
- 挑战契约为五站各三道 optional 挑战，共 15 道；现有六道主线谜题保留。每站支线含 observation 单选、multi_select 多选、matching 线索配对。支线可以跳过，不阻塞后续点位解锁或完整主线结局；正确性和积分以服务端判定为准。

## 验收项

- [x] 五站每站 13 个问题，全局覆盖六个主题，每站只展示适用主题。默认主题首轮保留五道原有主线入口题。
- [x] 原生选择控件与关联标签保留键盘操作；375px 浏览器验证未产生横向溢出，自由提问输入框可用。
- [x] 主题筛选、换一批、已问过滤、当前点位与角色过滤通过单元测试；浏览器验证主题切换，阿蘅三个园林点位不串点。
- [x] 保留单 NPC 与多人同场的发送流程；原有旅程浏览器测试验证推荐提问和自由输入，没有修改服务端对话生成规则。
- [x] Intro 说明 6 道主线、15 道可选挑战、三类交互、跳过支线不阻塞主线以及服务端判定边界。
- [x] 浏览器验证三类挑战完成、跳过全部挑战通关、回访、刷新恢复、主线三种结局与报告计分。
